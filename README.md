# Face Recognition Attendance System

A Face Recognition Attendance System built using Python, OpenCV, Tkinter, and MySQL.

## Features

* Student Management
* Face Dataset Generation
* Face Recognition
* Daily Attendance Tracking
* Date-wise Attendance History
* Login & Registration System

## Technologies Used

* Python
* OpenCV
* Tkinter
* MySQL
* PIL
